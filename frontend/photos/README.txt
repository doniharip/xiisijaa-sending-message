FOLDER FOTO KELAS
=================
Letakkan foto-foto kelas kamu di folder ini.

Format yang didukung: JPG, JPEG, PNG, WEBP
Nama file bebas, contoh:
  - foto1.jpg
  - kelas_2024.jpg
  - wisata.jpg
  - graduation.png

Setelah menambah foto, buka file:
  frontend/js/photos.js

Lalu daftarkan nama file fotonya di array PHOTOS.
Contoh:
  const PHOTOS = [
    'photos/foto1.jpg',
    'photos/kelas_2024.jpg',
    'photos/wisata.jpg',
  ];

Slideshow akan otomatis berputar menampilkan semua foto.
